# Hermes Agent - 本地 AI 助手

一个强大的本地 AI 助手，支持多会话管理、命令行交互和网页仪表板。

## 功能亮点

- **多会话窗口**: 支持同时打开多个对话窗口
- **命令行风格**: 类似终端的聊天界面
- **本地运行**: 所有数据存储在本地，保护隐私
- **跨平台**: 支持 macOS、Linux、Windows

## 快速安装

请查看 INSTALL.md 获取详细安装指南。

## 启动命令

```bash
# 启动网页仪表板
hermes dashboard

# 启动命令行界面
hermes

# 查看帮助
hermes --help
```
